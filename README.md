# 🏠 Wanderlust

A full-stack travel listing web application where users can explore, create, edit, and manage property listings.

## 🚀 Live Demo

👉 **[Visit Wanderlust – Live Website](https://wanderlust-2-t8ct.onrender.com/listings)**

## ✨ Features

- 🔐 User authentication & authorization
- 🏡 Browse property listings
- ➕ Create new listings
- ✏️ Edit and delete listings
- ⭐ Reviews & ratings
- 🖼️ Image uploads with Cloudinary
- 🗺️ Location-based listings
- 💾 MongoDB database
- 📱 Responsive UI

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Passport.js
- **Image Storage:** Cloudinary
- **Deployment:** Render
